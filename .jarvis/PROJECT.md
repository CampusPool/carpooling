# Project

## Goal
Campus-exclusive student carpooling/bikepooling for approximately 4,000 students, primarily intended to reduce campus parking pressure and offer convenient shared commuting.

## Users
Verified college students as ride hosts and passengers; authorized moderators/admins.

## Scope
Student verification and role control, car/bike ride offers and searches, safe seat booking, route/time matching, cancellation, reporting, expense sharing and usage analytics.

## Non-goals
Commercial ride-hailing/driver income; employee ride modes; unauthorized university authentication/timetable APIs.

## Constraints
SE two sprints: Oct 19–23 and 26–30; GitHub Project backlog due Oct 12. DBMS Level 3 needs Next.js + relational SQL + a second NoSQL/vector paradigm, advanced database features and approved two-person DBMS team.

## Done when
A working Next.js product demonstrates core ride lifecycle, database constraints and advanced queries, passes meaningful tests, and provides sprint videos plus SRS/SAD/Test Plan and DBMS evidence.
